# Office Sathi — अनुवाद भाषा पैक (translation language packs)

ये फ़ाइलें Office Sathi ऐप के “Translate · अनुवाद” में “डाउनलोड” दबाने पर अपने-आप आती हैं — इन्हें खुद खोलने की ज़रूरत नहीं।
बिना इंटरनेट वाले कंप्यूटर के लिए: यहाँ से .ospack फ़ाइल लेकर ऐप में “भाषाएँ → पैक फ़ाइल से जोड़ें” करें।
हर फ़ाइल की SHA-256 `packs.json` में है; ऐप बदली हुई फ़ाइल नहीं लेता।

Models: Mozilla Firefox Translations (MPL-2.0, unchanged) — see NOTICE.txt and LICENSE-MPL-2.0.txt.
